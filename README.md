**“이 그림, 수업 자료에 넣어도 될까요? 편집해서 굿즈로 판매해도 될까요?”**

문화유산 이미지를 찾는 것에서 한 걸음 더 나아가, **어디에 어떻게 사용할지에 맞춰 이용조건과 출처표시를 확인하도록 돕는 서비스**입니다.

> 위 링크로 운영 중인 시험 서비스를 바로 이용하세요. **프로그램 설치·소스 다운로드·개인 API 키 준비는 일반 이용자에게 필요하지 않습니다.** 이 GitHub는 서비스 소개와 개발 소스를 공유하는 공간입니다.

## 이렇게 사용하세요

| 순서 | 할 일 |
| --- | --- |

| ④ 조건과 출처 확인하기 | 이용조건, 추가 확인이 필요한 사항, 출처표시 문구와 기관 원문을 확인합니다. |

## 무엇을 도와주나요?

- **이미지 찾기:** e뮤지엄 자료를 검색하고 후보 이미지를 살펴봅니다.
- **목적에 맞는 조건 확인:** 공공누리 조건과 상업적 이용·변경 여부를 대조합니다.
- **불확실한 부분 구분:** 이용 가능 여부가 불명확하면 추가 확인이 필요하다고 안내합니다.
- **출처표시 준비:** 출처표시 문구를 만들고 기관 원문을 확인하도록 돕습니다.
- **일상적인 문장으로 검색:** 자료 이름뿐 아니라 찾는 이미지와 활용 목적을 문장으로 입력할 수 있습니다.

## 왜 만들었나요?

문화유산 이미지를 발견해도, 실제로 활용하려면 이용조건과 출처를 다시 찾아 읽어야 합니다. 같은 이미지라도 수업에 그대로 쓰는 경우와 편집해 판매하는 경우에는 확인할 조건이 달라집니다.

이 서비스는 **이미지 검색 → 사용 목적 확인 → 조건 대조 → 출처표시**를 하나의 흐름으로 연결합니다. 문화유산학 연구와 박물관 자료등록 실무 경험을 바탕으로, 문화유산 이미지를 활용하는 과정의 어려움을 줄이고자 만들었습니다.

### 로컬 실행

`heritage-guide-source.zip`을 내려받아 빈 폴더에 압축을 풀고, 그 폴더에서 아래 명령을 실행하세요. Node.js 22.13 이상과 pnpm을 사용합니다.

```sh
pnpm install
pnpm dev
```

Cloudflare Workers용 Vinext 소스입니다. 실제 검색에는 본인의 `EMUSEUM_SERVICE_KEY`, 이미지 링크 보호에는 `EMUSEUM_IMAGE_ENCRYPTION_KEY`가 필요합니다. 비밀값은 `.dev.vars` 등 서버 설정에 보관하세요. 검색 API가 연결되지 않으면 실제 결과를 표시하지 않습니다. Gemini는 선택 기능입니다.

이 소스는 서버와 API 설정이 필요하므로 GitHub Pages만 켜서는 검색 서비스가 실행되지 않습니다. 일반 이용자는 위 운영 사이트를 이용하세요.

### 공개 소스의 범위

운영 사이트의 소스에서 배포 식별자·운영 데이터·키를 제외했습니다. 작품 사진 대신 예시 표시를 사용합니다. 운영자 설정 화면은 기본 비활성 상태이며, 배포 환경에 맞는 신뢰할 수 있는 인증 구현이 필요합니다. 원래 Sites 인증 헤더를 그대로 신뢰하지 않습니다. 의견 저장에는 D1 `DB`와 `drizzle/` 스키마가 필요합니다.

`rights.ts`는 이용조건 판정 로직의 읽기용 발췌입니다. 실행에 필요한 나머지 모듈은 소스 ZIP에 있습니다.
